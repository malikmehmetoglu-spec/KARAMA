# كرامة كير — نظام العلاج الطبيعي لنادي الكرامة الرياضي

نموذج أولي لواجهة **السجل الطبي للاعب** ضمن نظام إدارة العلاج والتأهيل في نادي الكرامة الرياضي (حمص، سوريا).

> جميع البيانات المعروضة تجريبية.

## التشغيل
افتح `index.html` في المتصفح، أو فعّل **GitHub Pages** (Settings › Pages › Branch: `main`).

## الملفات
- `index.html` — صفحة السجل الطبي (نظرة عامة، سجل الإصابات، الجلسات، التاريخ الطبي، الصور والتقارير)
- `support.js` — مُشغّل خفيف للقوالب والتبويبات
- `assets/logo.png` — شعار النادي
